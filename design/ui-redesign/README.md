# 歧路 Diverge · 棋谱研究室 UI 方案

这套方案已落到项目正式界面。以「回看一次选择，发现另一种可能」为主线，覆盖扩展 Popup、棋盘悬浮窗、全盘分析工作台、导入弹窗、设置、明暗主题和各类状态。

## 视觉与组件

暖白纸面 `#f3f2ec`、正文墨色 `#243a32`、主操作墨绿 `#285a46`。引擎推荐使用蓝色，人类直觉使用琥珀色，严重损失与失败使用砖红。所有类别同时保留文字标签。深色为墨绿黑底，颜色随主题切换。

共享令牌位于 `ui/theme.css`，只作用于 Diverge 页面和两个悬浮组件根节点，避免改动棋类网站的全局颜色。主题默认跟随系统，Popup 与悬浮窗通过扩展存储同步；PWA 通过自身存储记住选择。各端以同一套视觉语义呈现，但扩展存储与独立网站存储仍各自独立。

系统无衬线字体承担操作与说明；宋体 / Georgia 仅用于少量阅读标题；SAN、评分、比例使用等宽字体。通用圆角 7–9px，窗体 12px；采用细边界与克制阴影，取消荧光效果。键盘焦点使用明确蓝色轮廓，尊重减少动画设置。

## Popup：进入复盘，而不是阅读参数

宽度 368px。顺序为品牌与「仅供复盘」 → 简短主张 → 全盘分析主入口 → 两个平台分析板入口 → 悬浮窗开关与直觉等级 → 折叠模型设置 → 公平竞技说明。

仅保留一个主操作。Maia 模型与 CDN 留在高级设置中；删除架构宣传与未经实测的 0ms / 60FPS 文案。Popup 不连接引擎，因此不显示“引擎就绪”。现有偏好存储、当前标签页面板开关、等级分同步、CDN 地址保存与国际化机制继续使用。

## 悬浮窗：当前局面优先

宽度 342px。标题条可拖动，右侧保留设置与收起操作，收起后为紧凑浮窗。顺序为局面结论 → 候选着法 → 全盘分析入口 → 引擎真实状态；模型下载时进度出现在顶部。保留前三至四个候选、概率、评价差和共识标识。

设置抽屉覆盖语言、直觉等级、棋盘视觉和模型规格。图标改为明确的设置符号，同时提供可访问标签。关闭抽屉和收起悬浮窗沿用原有交互。

| 状态 | 呈现与行为 |
| --- | --- |
| 赛前 / 未启动 | 显示真实未启动状态，等待合法分析局面，不伪装计算进度 |
| 对局进行中 | 守卫继续清空候选与结论；全盘分析按钮原生禁用，明确提示赛后自动解锁 |
| 赛后复盘 | 正常呈现结论、候选和全盘分析入口 |
| 下载中 | 下载百分比、已下载 / 总大小和速度；客户端缓存说明 |
| 加载失败 | 说明失败并提供设置与重试入口，避免“常驻启动中” |
| 关闭结算框 / 刷新 | 沿用既有完赛证据判断与解锁生命周期 |

`FairPlayGuard` 的判定与计算权限没有改动。新增原生 `disabled` 只是使按钮的键盘与视觉状态和既有保护锁一致。

## 全盘分析：棋盘 → 比较 → 回看

桌面三栏：左侧棋盘、导航、试演分支与走势；中间实战 / Maia 直觉 / Stockfish 推荐的纵向比较、局面说明与折叠引擎设置；右侧双方精度、关键步与完整记谱。保留「妙手 / 俗手」分类，不改变算法或给评分添加新含义。

1180px 以下合为两栏，关键步与记谱放到下方；720px 以下单列，按棋盘、当前局面、关键步 / 记谱排列。棋盘维持正方形与真实棋子 SVG，不替换棋谱或捏造分析数值。

无棋谱时给出明确导入和现有经典示例入口，未知分析值保持 `—`。无棋谱时禁用“重新分析”。导入弹窗覆盖 PGN、FEN、已完赛链接、文件上传与拖入的既有能力，补齐 Esc 关闭、焦点限制与返回、关闭后不可聚焦。PWA 离线壳加入共享主题资源并更新缓存版本。

## 可交互预览

在项目根目录运行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8768/design/ui-redesign/index.html`。

预览台直接嵌入正式全盘分析页和 Popup 的正式 HTML / CSS。Popup 在预览中使用内存适配层，不写入已安装扩展；悬浮窗直接实例化正式组件，提供赛后、未启动、锁定、下载和失败切换。悬浮窗里的数值明确标注为 UI 示例，页面不启动计算引擎。全盘页仍是真实应用，导入后会按需分析并下载模型。

本次不涉及发布部署、评分算法、模型权重或实时对局守卫修改。此前工作区已有的品牌图标、商店素材与其他未提交工作继续保留。
