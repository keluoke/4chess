# 超宽屏复盘工作台

## 交付内容

- 浏览器可用宽度达到 1800px 时启用全宽研究布局。取消 1800px 页面上限和共享棋盘 600px 上限；根据可用高度约束棋盘尺寸。2560×1080 视口默认棋盘约 789px，较上一版约 587px 增大约 34%（面积约增大 81%）。屏幕物理分辨率不等同于浏览器 CSS 视口。
- 原有走势图 DOM 移到中栏底部，保持分支数据、点击监听与原谱成绩。回到普通桌面/窄屏时移回棋盘下方，不复制图表、不重启引擎。
- 中栏采用紧凑精度摘要、评分条、并排引擎/直觉变化、独立滚动记谱；下方走势图常驻。右栏保留独立直觉扫描和关键步。深浅主题、专注模式与练习模式兼容。
- 两条分栏边界支持指针拖动和左右方向键，双击或 Home 恢复默认。宽度比例存于本地；恢复时重新受当前窗口宽高约束。分栏键盘操作不会触发行棋导航。存储不可用时仍可调整布局。
