- 方向键在页面各处回看；按钮或链接保留焦点时也生效。输入、可编辑文本、导入 / 设置 / 升变弹窗保持原生键盘操作，Tab / Enter / Space 的控件行为保留。
- 左键点击与拖动只提交合法着法；支持后 / 车 / 象 / 马升变选择。原实战记谱保持不变，个人分支可用方向键及原导航按钮回看，也可从“我的分支”重新打开。分支与手绘标记当前仅在本页会话保留，刷新不作为持久棋谱存档。
- 右键拖动绘制思考箭头，单击绘制 / 取消圆圈；重复同一箭头可取消，清除按钮只清除当前局面。标记按 FEN 保存，翻转 / 导航 / 引擎图层更新不会抹掉个人标记。
- 当前局面先于完整复盘展示；SF 与 Maia 独立加载及返回结果，两种先后顺序都可见。当前分支优先，返回主线并停止导航后恢复未完成复盘。取消的旧复盘结果不再终止新的单步搜索；只改变 Maia 时保留原 Stockfish Worker。
- SF 完整版下载显示进度；缓存、下载、准备与就绪不混淆。三入口统一保存 SF / Maia 档位、语言、Elo、主题与适用的显示偏好；新版插件在同一 Chrome 配置中通过只对 `https://4chess.cc/analysis` 开放的白名单连接同步。未安装 / 未启用连接时网页独立保存；不自动跨设备同步。
- 连接不传 PGN、FEN、模型、引擎指令或自定义 CDN 地址；不提供绕过公平竞技保护的入口。模型缓存依旧属于各站点，偏好同步不等于共享权重缓存。
- popup 新增语言选择；79M / 23M 与 SF 完整版在各入口都有中英文资源 / 等待提示，不保证更准确或给出固定耗时。插件中保持 SF Lite，完整版在网页使用。
