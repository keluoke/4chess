# 1.0.8：悬浮窗布局、主题与引擎说明

SF 选择在 popup / 悬浮窗标为“网页版复盘引擎”，两个选项不再暗示它们会切换悬浮窗。提示、使用指南、README、商店描述、隐私页及本地扩展复盘说明统一明确：悬浮窗固定 SF19 Lite，该偏好只影响网页版完整复盘。底部显示实际 Lite 与真实运行状态，Maia 型号正常随设置改变。

面板外框维持广告位或默认尺寸，并限制在可用视口；分析正文与设置在各自区域滚动。全盘入口和实际引擎状态固定可见，收起保持覆盖尺寸；较短面板的收起内容可以滚动。详细图例改为原生折叠说明，保留双引擎含义与完整图例入口。候选标题、着法、损耗与概率、引擎评分分别布局，长文本换行不撑大外框。设置标题保持可见，关闭渐隐动画，防止过渡中背景文字叠在设置上。

浅色主题修复强调着法沿用白字的问题，调深辅助灰与金色评分标签；深色使用对应主题变量。模型按钮把型号与下载大小分为两行。样式隔离外站控件字号、字距、边距等干扰。

验证：
- `test_floating_layout.mjs`：16 组浅 / 深、中 / 英、250 / 300 / 420 px、200 / 600 / 800 px 布局，包含模拟宿主控件样式干扰；外框不随内容长高、内部无行溢出、可达设置底部、收起恢复与固定入口 / 状态，关键小字号文本对比度至少 4.5:1。截图来自组件夹具，不作为真实棋局或模型效果证据。
- `test_user_entries.mjs`：真实打包 MV3，在活跃棋局夹具零模型请求、保护锁正确，原广告覆盖尺寸和收起尺寸一致；真实 Lite WASM、独立加载、失败重试与语言 / 模型设置。
- `test_native_popup.mjs`：实际原生 action popup，中英文、368×600、设置滚动和宿主隐藏 / 恢复。
- `test_preferences_sync.mjs`：真实扩展、popup、悬浮窗和第一方网页的偏好同步与刷新保存。
- `test_review_ui.mjs` 和 `npm test`：原复盘布局、原棋子 / 导航 / 声音、白方评分视角、引擎版本 / 缓存、守卫与安全回归。

本次不改变 SF 分发策略、推理实现或 FairPlayGuard 判定；大 Maia 权重仍仅来自 CDN，ZIP 不含标准版执行代码或大模型。
