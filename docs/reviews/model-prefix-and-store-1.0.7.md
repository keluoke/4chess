# 1.0.7：CDN 前缀与提审包

悬浮窗通过 `initialize(preferences.cloudflareCdnUrl)` 传入显式地址；原代码只对从 storage 读取的地址拼接模型文件名，显式目录地址会先请求目录本身。现由同一解析器处理完整 .bin 地址、目录前缀、尾部斜线、查询参数和模型版本，保留官方 CDN 回退。已知其他模型的文件名不作为当前模型使用，相对地址不回退到扩展本地大权重。

- 三档真实权重在打包 MV3 页面中加载与推理成功：5M 7,327,236 参数，23M 27,130,884 参数，79M FP16 83,094,020 参数；缓存复用无网络下载。此次冷加载加首步分别约 47 / 103 / 174 秒，含网络环境影响，不是其他设备的耗时承诺。
- Chess.com 合法分析页夹具，真实扩展悬浮窗与真实 5M：目录 override 最终只请求 `https://weights.4chess.cc/maia3_model.bin`，模型就绪且候选显示。平台内容为可复现夹具，未宣称覆盖平台未来所有 DOM 变化。
- 平台内容脚本不能直接建立跨源扩展 Worker 时，现有设计回退到页面线程，实际测试使用了该回退。这意味着大模型在悬浮窗中可能更影响页面响应；本次没有改动这项架构。
- 核心测试、原生 popup、三入口设置同步及公平竞技锁定测试通过。修改未触及 FairPlayGuard 判定。
- ZIP 保留本地 JS / Lite WASM 与轻量识别资产，排除 Maia 大权重、网页版 SF Standard 执行代码，根目录一个 manifest，版本 1.0.7。
- 更新既有中英文隐私页、商店填写说明与声明，覆盖 79M、复盘缓存、首方偏好连接、正常网络请求信息和分别清理站点数据。保留原隐私页布局与语言切换。

包可以作为提审文件，但本地验证不等于 Chrome Web Store 审核批准。开发者后台仍须填写用途、数据声明、权限理由、素材、审核说明及公开隐私政策地址。未代用户上传或提交审核。
