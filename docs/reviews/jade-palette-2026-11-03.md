# 复盘工作台绿色配色

以低饱和灰绿白底、石墨文字、翡翠绿和杏铜色组织工作台。引擎候选与棋盘箭头使用绿色，直觉箭头与概率使用杏铜色；走势图继续表示引擎评价，原谱/分支通过虚实线及标签区分。

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面底色 | `#F2F5F1` | `#111A17` |
| 卡片 | `#FFFFFF` | `#19251F` |
| 正文 | `#192C23` | `#EAF2EC` |
| 辅助文字 | `#596B5F` | `#A7B7AC` |
| 引擎与主操作 | `#146B49` | `#7BD6A5` |
| 直觉 | `#966033` | `#E5B580` |
| 选中与评分底色 | `#E5F1E9` | `#243E30` |

去除电蓝评分渐变、紫蓝背景及按钮荧光阴影；评分保留中性色文字以避免正负分数被主题色误导。棋盘、走子高亮、分支、图表、进度和交互焦点统一调整，候选箭头添加轻微轮廓阴影以改善在棋格上的辨识度。配色覆盖仅限分析工作台，沿用共享颜色变量兼容现有图表及棋盘组件。

验证：`node scripts/test_position_analysis.mjs`、`node scripts/test_review_ui.mjs`、`npm run build`、打包完整性和 `npm run test:browser` 均通过。检查超宽屏、普通桌面、窄屏以及深浅主题截图；评分辅助文字与浅绿底对比度约 4.9:1，绿色/杏铜色文字与白底约 6.5:1 / 5.2:1。浏览器采用真实 Stockfish、可控 Maia 数据；不据此宣称实际 Maia 模型性能或实体移动设备验收。

扩展版本升至 1.1.7。本地截图 `artifacts/workbench-ultrawide-2560.png` 与 `artifacts/workbench-ultrawide-dark.png`，不入库。
