# Diverge 1.1.11：双方总览、质量与直觉双标签、连续重试

日期：2026-11-10。

## 用户流程

1. 完成全盘评分后，侧栏显示白方、黑方两个统计列。互斥分类为最佳、好棋、不精确、失误、大漏着、强制着法、未完成，每列之和等于该方已载入着法数。开局库、突破直觉、直觉陷阱单独列出，允许与质量分类重叠，不计入质量之和。
2. 点击某方的分类数量，筛出对应着法并移至列表；可切换双方、白方或黑方。“关键局面”保留重要错误与已确认直觉局面，“全部着法”覆盖全部载入着法。明显失误筛选包含失误和大漏着；不精确可从统计表单独查看。默认筛选采用进入本次棋谱时的棋盘视角，此后翻转棋盘不改变所选方，也不将方向当作实际执棋身份。
3. 卡片同时展示质量与直觉标签，例如“失误 · 直觉陷阱”，说明相对搜索最佳的损失，以及可用的等级条件下 Maia 预测概率或自然选择的损失。点击卡片/着法回到落子前局面；现有走势图和记谱定位保留。
4. “练习所选局面”将当前方与分类下可训练的错误及已确认直觉局面组成队列。未知、强制着法及组合延续不会单独生成练习题。支持逐题重试、起点提示、查看答案、跳过和结束。
5. 练习期间隐藏候选、评分、后续记谱和直觉侧栏；普通导航快捷键不会翻到后续答案。沿用深度验证和容许合理替代走法的判定；提示、答案及判分复用同一次加深搜索，参考深度不足不提供提示或成功结论。区分独立找到、提示后找到、已查看答案、仍需重试和判断未完成；查看答案不算独立找到。已取得的成功不会因之后探索其他选择而被抹掉。
6. 结束时显示本组结果，卡片回写本次练习状态。记录只保留在当前棋谱会话，不代表长期掌握；新棋谱、引擎切换和重新评分会清理旧状态。

## 判定与状态边界

- `engine/review-policy.js` 集中质量分类、双方计数、选择与可练习策略。`GameAnalyzer` 复用相同误差分级函数，阈值保持原有 0.40 / 1.00 / 2.00 兵，不改精度分数的预期得分算法，不声称等同于 Chess.com 的私有评分。
- “最佳”需要实战 UCI 与搜索首选一致，包括升变棋子；低损失本身不等于最佳。未知评分不会成为好棋或练习题；强制着法单列。
- 所有分类从完整 `allMoves` 派生，不从 `keyMoments` 子集推算整盘。直觉数量未完成扫描时显示“—”；明确未确认的标签不计入确认结果，组合延续不重复统计。部分解析棋谱明确说明只覆盖已载入着法。
- 练习保存独立的队列快照，异步判分绑定棋谱世代和练习世代。退出、导入、切换和来源撤销后的迟到结果不能改写棋盘或把下一局误记为成功。
- FairPlayGuard 及实时对局保护逻辑未修改；沿用开始练习、判分前后和来源锁定的保护检查。
- 新的 `analysis/review-explorer.js` 及依赖进入 PWA 缓存，更新缓存版本；不清除模型缓存，不添加模型资产或权限。

## 验证

- `npm test`：现有回归加新策略与练习状态测试，覆盖分类边界、双方互斥计数、标签重叠、严格未知、升变身份、未确认标签、组合去重、提示/揭晓归因、浅层判分不通过，以及切换棋谱的异步隔离。
- `npm run test:review-explorer`：真实 Chromium 的完整工作台 UI，使用合成已结束棋谱与受控评分，覆盖双方统计点击、双标签、未扫描/未完成状态、回到落子前、翻转不改筛选、真实棋盘走子进入判分、练习隐藏答案、导航快捷键、队列推进、中文/英文、390px 手机宽度和新会话清空。
- `npm run test:browser`：页面导入、PWA 首次离线重载、字体缓存、打包扩展加载，以及实时保护/结算/关闭弹窗/刷新/新局保护的模拟页面回归。
- `npm run test:floating-handoff`：当前商店包的网页与扩展工作台交接及视角保留。测试修正了扩展新建标签首次导航可能绕过路由拦截、导致线上旧 HTML 与本地新模块混用的问题：先创建可观察的空白目标，再导航至被拦截的测试地址；禁用该代理场景的网页 Service Worker，PWA 离线能力仍由独立测试覆盖，并断言无未捕获页面错误。
- `npm run build`、`npm run package`、`node scripts/test_package_integrity.mjs`：模块依赖、体积、商店包/解压目录一致性检查；CI 增加本次复盘浏览器测试。

视觉检查素材保存在 `artifacts/review-explorer-20261110/`：桌面中文/英文、手机中文与双标签卡片。素材采用合成数据，不作为生产引擎质量或真实账号结果。
