# Scan 1.1.3：自动进入棋盘与设置流程

日期：2026-10-14。安装包：`releases/diverge-extension-v1.1.3.zip`。

## 交互变化

- 用户点击扫描后自动定位和识别，成功直接进入可确认、可修正的互动棋盘；失败才显示截图框选。修正区保留“重新框选棋盘”，用于改选其他棋盘。识别失败后同一截图可继续框选重试；结果被接受后立即释放 offscreen 截图，失败缓存最长两分钟。
- 棋盘下方“视角”只改变观看方向，不改变 FEN。“修正识别方向”只出现在修正区，带用途说明，会把棋子重新对应到旋转后的坐标并清除不可由图像断言的易位 / 吃过路兵权。修正区可以展开 / 收起，直接点选棋子或删除工具修正方格，草稿保存在会话中。
- 深入分析按钮改为“深入探索引擎与直觉的分歧”，英文为“Explore engine vs intuition”；交接的仍是当前确认局面与已保存的网页引擎 / Maia 偏好。
- 设置齿轮改为 21px、较粗笔画和 32px 点击区，浅深主题继承明确的文字颜色与背景。设置进入独立页面，顶端“返回扫描棋盘 / 返回首页”，内容独立滚动，Esc 也可返回。返回保留当前 FEN、观看方向、个人分支与修正状态；确认过的局面恢复计算。打开设置会停止当前搜索。
- 设置仍复用原有控件、保存与同步逻辑，SF19 Lite / Standard 网页偏好及 Maia 5M / 23M / 79M 均保留。未新增权限、引擎或模型。识别核心及后处理源哈希仍为 `e840c01048bb…`。
