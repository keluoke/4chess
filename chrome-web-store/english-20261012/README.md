## Source and provenance

- Screenshots 1 and 3 use the project's current `IntuitionPanel` component. The editorial framing is store artwork, rather than a capture of a third-party chess website.
- Screenshot 1 uses genuine Maia-3 5M and Stockfish 19 Lite results for the position before 10. Nxb5 in the completed Opera Game. Predictions, evaluation, legal board position and game review are preserved in `source/engine-evidence.json`.
- Screenshot 2 includes an actual English Review Studio browser capture, generated by importing and analyzing the completed game. Its Chinese-language switch is hidden for this English-only asset.
- Screenshot 3 renders the component's real locked state with its review button disabled and no candidates. This component rendering is artwork, not evidence of installed-extension behavior on a live platform.
- Presentation CSS omits the panel's static visual-help block to keep the primary controls fully visible. The illustration sources retain their original engine evidence; captions now reflect diagram study as well as game review. The whole-game screenshot remains a completed-game example, and the locked panel remains a component rendering.
- Promotional tiles reuse the existing brand icon and an editable vector interpretation of its branching paths. They were rendered directly from HTML/CSS/SVG without AI-generated interface images.

## Reproduce

Run from the repository root:

```sh
node chrome-web-store/english-20261012/source/capture.mjs
node chrome-web-store/english-20261012/source/render.mjs
```

The capture step runs actual engines and may download the Maia model into the browser cache. It does not save model weights in this asset directory. Scripts use the bundled Playwright/Sharp runtime and local Chrome; adjust the dependency paths when using another machine.

`qa/report.json` verifies dimensions, RGB/no-alpha PNG format, English-only visible text and disabled review controls in the locked composition. All five final images were also visually inspected at half size.

Specification reference: [Chrome Web Store image guidelines](https://developer.chrome.com/docs/webstore/images).
